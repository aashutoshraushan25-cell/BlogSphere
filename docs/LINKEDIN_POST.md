### 💡 What is BlogSphere?
BlogSphere is a full-featured publishing ecosystem designed to give writers and readers a fast, distraction-free environment with personalized analytics and strict resource ownership controls.

---

### 🛠️ Key Features & Highlights:
🔒 **JWT Authentication & Security**: Complete stateless authentication flow with bcrypt password hashing (10 salt rounds), secure token storage, and client-side route guards.
📊 **Creator Dashboard**: Real-time writing analytics including lifetime published posts, total words written, and dynamic status metrics.
📝 **Full CRUD & Ownership Control**: Create, Read, Update, and Delete articles with server-side authorization checks (`HTTP 403 Forbidden` protection against unauthorized modifications).
🔍 **Instant Search & Taxonomy**: Real-time multi-field search and category filtering with server-driven pagination.
📱 **Responsive & Glassmorphic UI**: Built with pure CSS3 custom properties, glassmorphism, responsive navigation, and zero horizontal overflow across 320px–1440px+ screens.
⚡ **Health Check & Production Ready**: Modular Express 5 backend with comprehensive error handling, dynamic CORS, and an automated E2E test suite passing 43/43 assertions.

---

### 💻 Technology Stack:
- **Frontend**: HTML5, Modern CSS3 (Variables & Glassmorphism), Vanilla JavaScript (ES6+)
- **Backend**: Node.js, Express.js (v5.x)
- **Database**: MongoDB & Mongoose ODM
- **Authentication**: JSON Web Tokens (JWT) & bcryptjs
- **Testing & Tooling**: Node test runners, Postman, Git & GitHub
